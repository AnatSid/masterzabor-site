# Benefits Icon Size Options

These files are design references for the homepage benefits block icon rendered size.

## Options

- `CURRENT-40px.html`: 32 mobile / 40 desktop = production baseline before the experiment.
- `MEDIUM-48px.html`: 40 mobile / 48 desktop = candidate.
- `LARGE-52px.html`: 44 mobile / 52 desktop = candidate, `SELECTED`.

## Rules

- SVG artwork is identical in all variants.
- Only rendered size changes.
- Production assets are loaded from `public/icons/benefits/`.
- Do not create separate SVG copies for `CURRENT`, `MEDIUM`, or `LARGE`.
- Final selected option: `LARGE` = 44 mobile / 52 desktop.

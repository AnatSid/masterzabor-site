## Часть 1. Домен и порядок работы

### Домен: `masterzabor.by`

Хороший выбор: содержит ключевое слово «забор», без дефиса, легко запоминается, подходит для всей Беларуси (нет привязки к городу).

### Правильный порядок

```
1. Создать сайт локально (на своём компьютере) ← ТЫ ЗДЕСЬ
2. Протестировать на localhost:3000
3. Залить код на GitHub
4. Зарегистрировать домен masterzabor.by на hoster.by (~25 BYN/год)
5. Создать аккаунт на Vercel, подключить GitHub
6. Привязать домен → сайт онлайн
```

Домен и хостинг нужны только на шаге 4-6. Сначала — код.
